# Supplied knight permission and provenance

The project owner supplied `knight/source/knight_combat.fbx` and the accompanying texture maps. On 17 November 2026, the owner clarified that their friend created the character, and explicitly confirmed permission to publish the model, textures, and modified versions in this public GitHub repository.

This is a project-specific permission record. No Creative Commons license, public-domain dedication, or transfer of copyright is asserted. The artist's name was not supplied. Questions about reuse beyond this project should be directed to the project maintainer.

The original source is retained in `knight/`. `scripts/import-knight.py` removes the sword, shield, dagger and embedded scabbard components, assigns PBR maps, adds a rigid shoulder hinge and bevel, and exports the runtime GLB. The editable converted Blender scene retains packed source textures. Original animation clips were not present; this game's CMU motion provenance remains separately documented.
